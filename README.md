# ⏱️ Timeline Tracker

A personal productivity and time-management application designed to help you organize your day, manage routines, stay focused, and keep track of how you spend your time.

## ✨ Features

### 🏠 Home Dashboard
- Live digital clock and date.
- Dynamic time-based greetings.
- Live session progress with circular progress indicator.
- Current and upcoming session information.
- Interactive daily timeline.
- Session completion animations.

### 📅 Session Management
- Create, edit, and delete sessions.
- Set custom start and end times.
- Organize sessions using categories.
- Add descriptions and instructions.
- Schedule sessions for specific dates.
- Configure recurring schedules.
- Detect overlapping sessions.
- Configure session pre-alerts.

### 🔔 Smart Announcements
- Automatic time announcements.
- Custom announcement intervals.
- Voice-only, sound-only, and combined announcement modes.
- Customizable spoken messages.
- Multiple voice profiles (browser dependent).
- Adjustable speech rate and pitch.
- Repeat announcements.
- Custom bridging phrases.
- Announcement tones and volume controls.

### ⏰ Session Pre-Alerts
- Configure alerts before scheduled sessions.
- Customizable pre-alert intervals.
- Voice and sound notification modes.
- Custom announcement messages.
- Adjustable voice and sound settings.

### 🎵 Sound & Audio
- Customizable announcement tones.
- Session completion sounds.
- Adjustable sound volume.
- Configurable sound repetition.
- Optional audio ducking where supported by the browser.

### ⚙️ Personalization
- Dark and light themes.
- Custom username and greetings.
- Custom session categories and icons.
- Always-On Display settings.
- Customizable voice announcement profiles.

### 📊 Timeline & Data Management
- Browse daily and upcoming timelines.
- Search sessions across dates.
- Filter sessions by weekdays and weekends.
- Export session data to CSV.
- Import previously exported CSV data.
- Manage and reset application data.

## 🚀 Deployment

This application is built using HTML, CSS, and JavaScript.

It can be hosted as a static website using GitHub Pages.

### GitHub Pages Setup

1. Fork or clone this repository.
2. Open repository Settings.
3. Navigate to Pages.
4. Select **Deploy from a branch**.
5. Select the `main` branch.
6. Select the `/ (root)` directory.
7. Save your settings.

Your application will be available at:

`https://YOUR-USERNAME.github.io/timeline-tracker/`

## 📱 Compatibility

Designed with a mobile-first interface and responsive layouts.

- Android browsers
- Desktop browsers
- Chrome-based browsers
- Other modern browsers with varying feature support

## ⚠️ Browser & Background Limitations

Some features depend on browser and operating-system capabilities.

- Voice announcements depend on browser speech synthesis support.
- Audio ducking depends on Audio Session API support.
- Background timers may be throttled by browsers.
- Announcements are not guaranteed when the browser is suspended, closed, or terminated.
- Native Android audio focus and guaranteed background alarms require additional native Android integration.

## 💾 Data & Privacy

The application is designed for personal use. Session data and settings are managed locally by the browser.

Export your data periodically to maintain a backup.

Clearing browser storage or website data may erase locally stored information.
